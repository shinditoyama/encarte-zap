# 🛒 Supermercado Digital: Encarte Interativo

Uma solução full-stack moderna para supermercados, transformando o encarte semanal estático em uma experiência digital interativa com foco em conversão via WhatsApp.

## 🚀 Funcionalidades Implementadas

### Landing Page (Cliente)

- _Encarte Digital Interativo:_ Grid de produtos dinâmico com preços atualizados em tempo real.
- _Lista de Compras Inteligente:_ Adição de produtos a um carrinho persistente (LocalStorage) via Zustand.
- _Receitas do Dia:_ Sistema de cross-selling onde ingredientes de receitas podem ser adicionados à lista com um clique.
- _Conversão via WhatsApp:_ Geração automática de mensagem formatada com os itens da lista e total estimado.

## 🛠️ Stack Utilizada

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org)
- **Estilização/UI**: [Tailwind CSS](https://tailwindcss.com) + [Shadcn/ui](https://ui.shadcn.com)
- **State Management**: [Zustand](https://zustand-demo.pmnd.rs)

## ⚙️ Configuração do Ambiente

### 1. Clone o repositório:

```bash
git clone https://github.com/shinditoyma/encarte-zap.git
```

### 2. Instale as dependências:

```bash
npm install
```

### 3. Rodar em Desenvolvimento

```bash
npm run dev
```
